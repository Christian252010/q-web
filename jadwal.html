Kalkulator Rumus

Hitung rumus dan persamaan dengan mudah

Rumus

Operator: + - * / // % **. Persamaan menggunakan =. Perkalian seperti 2x juga didukung.

Variabel

0 variabel
Masukkan rumus terlebih dahulu.
Hasil
—
Masukkan rumus dan nilai variabel.

Cara menggunakan

Masukkan ekspresi matematika atau persamaan.

  • + penjumlahan
  • - pengurangan
  • * perkalian
  • / pembagian
  • // pembagian bulat
  • % modulus
  • ** pangkat
  • 2x perkalian implisit
  • sqrt(x) akar
  • sin(x), cos(x), tan(x)
  • asin(x), acos(x), atan(x)
  • log(x), log10(x)
  • abs(x)
  • floor(x), ceil(x), round(x)
  • min(a,b), max(a,b)
  • pi dan e

Untuk mencari suatu variabel, gunakan persamaan dan kosongkan tepat satu variabel.
